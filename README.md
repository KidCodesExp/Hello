# WordsAnalyser

Professional, local-first file & text analysis — 100% in your browser.

## Features

- **Drag-and-drop file analysis** — TXT, MD, CSV, JSON, XML, HTML, CSS, JS, RTF, LOG, PDF, DOCX (via PDF.js + Mammoth.js)
- **Real-time analysis** — words, characters, sentences, paragraphs, reading/speaking time, unique words, longest/shortest word, top-frequency list
- **Export** — copy results, download as TXT, CSV, or JSON
- **14 working text tools** — case converter, text cleaning, comparison, keyword density, duplicate detection, find & replace, sorting, reversal, and more
- **Zero backend** — no servers, no uploads, no tracking

## Deploy

### GitHub Pages
1. Push to a repository
2. Settings → Pages → Source: `main` branch, root
3. Done — no build step

### Netlify
1. Drag the folder onto netlify.com or connect the repo
2. Publish directory: `.` (root)
3. Done
