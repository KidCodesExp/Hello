Privacy

Your files
never leave your device.

WordsAnalyser runs entirely in your browser. Nothing is uploaded, stored, or transmitted.

100% Local Processing

Every file is read and analysed inside your browser using JavaScript. No server, no backend, no network request.

No Uploads

Your documents are never uploaded to any external server — not ours, not any third party. There is no server.

No Permanent Storage

Uploaded files live in memory only, for the current session. Close the tab and everything is gone.

Session-Only History

Your "recently analysed" list is kept in memory for convenience. It is wiped on refresh or via the Clear Dashboard button.

No Tracking

No analytics, no cookies, no fingerprinting. WordsAnalyser does not track you.

Full Control

Remove any file at any time with the ✕ button. Clear everything with one click in the dashboard.

Privacy Policy

Effective: 2026 · WordsAnalyser

WordsAnalyser is a client-side text analysis tool. All file parsing, text analysis, and export happen locally in your web browser. No user data is transmitted to any server. No uploaded files, text content, or analysis results are stored by WordsAnalyser beyond the current browser session.

Because processing is entirely local, WordsAnalyser cannot access, view, or retain your documents. This is not a promise — it is a technical property of the software.

Fonts are loaded from Google Fonts. PDF parsing uses Mozilla's PDF.js and DOCX parsing uses Mammoth.js — both loaded from public CDNs and running locally in your browser. No data is sent to these CDNs by the app; only the library code is fetched.

By using WordsAnalyser you agree that you are responsible for the files you process and that WordsAnalyser holds no liability for the content of files you analyse.

Questions? Email privacy@wordsanalyser.app.
